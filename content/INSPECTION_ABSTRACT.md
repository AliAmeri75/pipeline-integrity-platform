This web application supports reliability- and risk-informed selection of fixed
pipeline intervention intervals. It compares prior excavation scheduling
without inline inspection (ILI) against pre-posterior, ILI-informed scheduling
for systems containing multiple pipe joints. Monte Carlo simulation represents
uncertain crack initiation, crack growth, detection, sizing, repair, leakage,
and burst events.

The current version is intended as a transparent research and demonstration
tool. Users define their pipeline and initial cracks in Data Exploration, then
reuse the saved dataset here. They can select separate prior and ILI candidate
intervals, adjust the planning assumptions, and calculate net VoI as the
minimum safe prior cost minus the minimum safe ILI-informed cost.
