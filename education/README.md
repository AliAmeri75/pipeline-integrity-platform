# ALIRIM educational tutorial

This folder contains the student-facing learning module that connects the three
ALIRIM research applications. It teaches one simple workflow:

1. understand the ILI crack inputs;
2. calculate failure pressure;
3. represent uncertainty with probability-density plots;
4. estimate probability of failure with Monte Carlo simulation;
5. interpret the result as a maintenance discussion; and
6. complete a short knowledge check.

The failure-pressure equations in `pof_model.py` are adapted from `CorlasP.py`
in the `AliAmeri75/pipeline-inspection-app` repository at commit
`b479e41116ad560465676b01a67e8e28aa9c1f85`.

The thresholds and actions shown in the tutorial are illustrative classroom
prompts, not engineering acceptance criteria.
